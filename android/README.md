# Fenland Angels Radio — Android

Native Android listener app for Fenland Angels Radio.

## v1 goals
- Live StationHQ stream
- Native Media3 / ExoPlayer playback
- MediaSessionService background playback
- Lock-screen and notification media controls
- Survive normal app backgrounding independently of the FAR PWA

## Stream
The initial development stream is:
https://hq3.yesstreaming.net:7085/stream

## Development
Open the `android` directory as a project in Android Studio.

This project is intentionally separate from the existing `/app` PWA.
